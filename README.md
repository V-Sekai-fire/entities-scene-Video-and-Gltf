# entities-scene-Video-and-Gltf

A social VR world project, started from the platform's default world scene, meant for video and glTF content.

## What it is for

The project holds the default world scene, the platform's world SDK packages and its utility behaviour scripts. No video or glTF content is in it yet.

## Build and run

Open the folder in the editor version that `ProjectSettings/ProjectVersion.txt` names; the package manifests pin the world SDK.
